# User Profile: Li Wei (Product Manager, trip owner)

## Communication Style

- PM mindset; reads updates through timelines, ETA, status, owner, and blocker lens
- Busy and direct; expects concise bullets first, detail on request
- Replies in whichever language she opened the conversation (Chinese or English)
- Prefers scannable docs over prose; dislikes hedging
- Will respond to direct questions but dislikes being asked about obvious items
- Tech-comfortable — uses Notion, Feishu, and Google Calendar daily; expects tools
  to be used well, not avoided

## Authorization Scope

| Action | Authorization | Notes |
|--------|---------------|-------|
| Routine info lookup (weather, flight status, directions) | No approval needed | Act first, summarize after |
| Maintain follow-up checklist / write Notion journal / create calendar entries | No approval needed | Free — keep current |
| Book refundable flight/hotel within budget | No approval needed | Prefer refundable options early |
| Book non-refundable, or single transaction > ¥5,000 | Ask first | |
| Cancel or change a confirmed booking | Ask first | Propose, don't execute — even after a disruption |
| Make trip-date change or multi-day re-sequence | Ask first | |
| Exceed ¥60,000 total budget cap | **Never** | Red line |
| Make medical decisions (dosing, clinic choice, fitness-to-fly) | **Never** — defer to Li Wei | Surface info, do not prescribe |
| Interpret visa / customs policy as binding | **Never** — quote rule, link source | Li Wei (or a consulate) decides |
| Put passport numbers, DOB, or home addresses in plain email body | **Never** | Reference attachment or doc ID instead |

## Habits

- Uses "asap" to mean "respond within the same stage" — don't defer to the next
  stage. If that is not possible, flag it up-front
- Wants CNY amounts stated explicitly ("¥4,380"), never rounded ("~4k")
- Carries her parents' first-international-trip weight — leans "over-prepared over
  surprised at the airport"
- Holds a hard ¥60,000 cap; wants to see running totals, not optimistic rounding
- Communicates mostly through Notion / Feishu / Google Calendar rather than email
