# Available tools

Nine MCP servers are available. Flight booking provides `search_flights`, `get_flight_offer`, `get_flight_status`, `list_bookings`, and `create_booking`. Hotel booking provides `search_hotels`, `get_hotel_details`, `get_room_availability`, `list_reservations`, and `create_reservation`. Banking provides account and transaction listing. Calendar provides event creation, listing, search, update, and detail. Notion provides page search, creation, block append, and block reading. Email provides paged listing, search, reading, drafting, and sending. Maps provides place search, place details, directions, and distance matrices. Visa and advisory provides entry checks, advisories, and subscriptions. Weather provides current, hourly, daily forecasts, alerts, and typhoon tracks.

Queries are pre-authorized. In-budget cancellable holds are allowed; non-refundable bookings, over-budget actions, cancellation or rebooking, and external sends require explicit confirmation.
