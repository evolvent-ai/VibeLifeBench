# Old-home renovation rental — calendar data

This environment contains one calendar, twenty-two distinct events, sixteen attendee records, and sixteen reminders. The history covers owner commitments, maintenance, property access, inspections, deliveries, family time, and tentative renovation windows known at Stage 0.

Later events may be created or updated only after the relevant acceptance, delivery, viewing, and authorization facts are available. The initial calendar does not contain a completed future handover.

`init.sql` is deterministic and uses synthetic participants.
