# Old-home renovation rental — listing data

The initial platform state contains nine agents, twenty-three listings, eighteen market-stat records, and five saved listings. The property's own inactive preparation profile appears alongside nearby rentals with different prices, availability, furnishing, transit, floor, and status.

Later publication, price, viewing, and availability facts must be established through the staged workflow. The seed does not predeclare that the renovated home is ready for immediate occupancy.

`init.sql` is deterministic and uses synthetic property and account identifiers.
