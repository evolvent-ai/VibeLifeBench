# Old-home renovation rental — email data

The Stage-0 mailbox contains one account, three folders, forty-three messages, and seventeen attachment records. Correspondence covers property management, utilities, insurance, maintenance, logistics, tax, appliances, and prior rental workflows, with separate senders, dates, subjects, and source authority.

Emails representing later quotes, inspections, or acceptance results are absent until their dated mutations run. The mailbox therefore preserves first-visible timing for each formal update.

`init.sql` is deterministic and uses synthetic addresses and attachments metadata.
