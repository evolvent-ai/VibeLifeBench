# Old-home renovation rental — notification data

Stage 0 contains twelve official accounts, ten account subscriptions, twenty official posts, and thirteen ordinary notifications. They provide concise updates from building management, utilities, tax, insurance, maintenance, weather, storage, and service channels without replacing the underlying email, listing, banking, or inspection records.

Later pressure claims and formal acceptance notices are absent initially and enter through their dated mutations. Source and payload fields allow the Agent to distinguish an unverified claim from an official update.

`init.sql` is deterministic and uses synthetic account data.
