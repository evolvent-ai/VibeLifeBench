# Old-home renovation rental — ecommerce data

The catalog contains twenty-five products with matching SKU and stock records, five saved addresses, seven expired coupons, four historical orders, and an empty cart. Products cover essential appliances, renovation materials, hardware, lighting, safety devices, and higher-cost alternatives with varied prices, ratings, demand, specifications, and return policies.

Stage 0 contains no completed order. Purchase records can only be created after the task reaches the required authorization and readiness conditions.

`init.sql` is deterministic and uses synthetic seller and inventory data.
