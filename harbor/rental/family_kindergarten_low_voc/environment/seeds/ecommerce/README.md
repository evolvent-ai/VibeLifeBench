# Family kindergarten rental — household product data

This environment contains six individually described products with matching SKUs and stock records, plus an empty household cart. The catalog covers child window locks, corner protection, anti-tip hardware, an air-quality screening device, and nearby alternatives with different return terms and availability.

The data supports price and suitability research only. Stage 0 contains no order, payment, or completed purchase.

`init.sql` is deterministic and uses synthetic merchant data.
