# Family kindergarten rental — map data

This environment contains eight places, two roads, two transit lines, eight stops, and ten timetable rows. The places connect candidate communities with the kindergarten, the CBD workplace, and ordinary neighborhood services.

Road and route changes released later in the task are absent from Stage 0. Each place and route relationship supports a distinct walking, cycling, transit, or peak-commute question.

`init.sql` is deterministic and does not contain a hidden answer marker.
