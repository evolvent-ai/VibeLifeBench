# Family kindergarten rental — email data

The mailbox contains one account, three folders, and six distinct Stage-0 messages. Threads cover property maintenance hours, lease wording, kindergarten logistics, moving questions, and ordinary household correspondence from different senders and dates.

Emails released by later mutations are absent from the initial seed. Message bodies are channel-appropriate source records and are not copied from task notifications.

`init.sql` is deterministic and uses synthetic addresses.
