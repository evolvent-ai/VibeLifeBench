# Family kindergarten rental — community review data

This environment contains three merchant/community records and six reviews written at different times by different users. The reviews cover daytime sound, lifts and fire access, child activity areas, dampness or mold observations, renovation odor, and property response quality.

Later review updates are absent from Stage 0 and arrive only through task mutations. Each review contributes a separate observation and provenance trail.

`init.sql` is deterministic and uses synthetic reviewer identities.
