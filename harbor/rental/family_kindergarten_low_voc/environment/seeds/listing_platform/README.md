# Family kindergarten rental — listing data

The Stage-0 catalog contains four agents, six rental listings, and six district market-stat records. Listings differ in rent, fixed fees, room count, move-in date, renovation history, building access, child-safety details, written terms, and current status.

The records provide a natural shortlist with both plausible and unsuitable options. Later description, price, and availability changes are applied only by their dated mutations.

`init.sql` is deterministic and uses synthetic people, property identifiers, and contact details.
