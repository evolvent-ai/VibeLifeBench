# credit_card environment for college_529_room_board_guard_30d

Historical household and school records for a 529 room-and-board review, including enrollment, cost-of-attendance, housing, meal, scholarship, cashflow, calendar, and education-note context. Later facts are released through staged mutations.

The seed is deterministic, schema-valid, and shared byte-for-byte between the task-local and canonical environment directories.
