# Tools

- calendar: read school, intensive-training, personal-training, recovery, sleep, and item reminders; create or adjust only personal entries.
- health_tracker: read sleep, steps, heart rate, workouts, and sync status; mark missing data instead of filling it.
- notion: maintain the control hub, stage records, risks, authorization, and review.
- email: read provider and school notices; never send, reply, forward, or confirm provider mail.
- weather: read forecasts, wind, rain, low temperature, and alerts; refresh before outdoor training.

Do not use review_platform or ecommerce.
