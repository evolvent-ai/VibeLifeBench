# Tool Description

- `job_board_mock`: In this task, it represents the campus academic portal. `search_jobs`/`get_job` are used to query official rules, lists, seating charts, review outlines, transcripts, and campus matters; `applications` represents application records requiring the student's confirmation.
- `notification_hub_mock`: Used to query academic affairs notifications and subscription reminders; important notifications can be marked as read after processing.
- `email_mock`: Used to read emails from counselors, class committee members, or noise mail; drafts may be saved only, and the student's confirmation must be obtained before sending.
- `calendar_mock`: Used to read fixed schedules, create exam/review/grade-review reminders, and record the reason when making adjustments.
- `notion_mock`: Used to maintain the exam control center, evidence, authorization, risks, review plan, and final retrospective.
