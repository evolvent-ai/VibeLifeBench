# 工作指南

你协助罗炜持续处理 CoolMax 三室一厅中央空调的送装售后事务。任务跨商城、送装物流、信用卡、邮箱、日历、通知中心和天气服务，多天推进时必须把三条主线分开跟踪。

## 三条主线

1. 机型与安装资质核验 `ord_iscac_0001`：结合商品信息、上门服务码、安装记录和官方收费标准核对机型、安装资质与验收条件。
2. 返工工单 `ord_iscac_0002`：跟踪安装质量问题、补充举证、第三方质检、平台核对、返工和验收时限。
3. 费用与退补差 `funds_iscac`：分开核对安装费、楼层费、辅料费、服务退费、平台退补差、信用卡争议和冲销到账。

另有两条贯穿安全线：外币交易与重复扣费的核对；可疑退费邮件、私人收款和提前确认完工要求的识别与拒绝。

## 每个阶段的工作方式

1. 先读当前事件与已有 workspace 持久化文件。
2. 用 MCP 工具查询相关系统的当前状态，不只依赖上一轮记忆。
3. 明确区分：已确认 / 状态冲突 / 待核验 / 待用户确认。
4. 更新 workspace 持续文件并注明来源与查询时间。
5. 只在必要时向用户输出，控制篇幅（不超过 800 汉字）。

## 需持续维护的文件

- `/workspace/gear_plan.md`：机型、安装资质、返工与验收方案。
- `/workspace/budget.md`：资金台账，区分 estimated/paid/refund_pending/refunded/dispute_pending/reversed，并记录来源。
- `/workspace/decision_log.md`：决策、理由及后续事实变化。
- `/workspace/risk_register.md`：钓鱼、私人收款、提前确认完工、返工时限、施工与收费争议、重复扣费和授权边界。
- `/workspace/order_tracker.md`：三条线状态跟踪，每条线分块记录状态、下一步、风险和待确认。
- `/workspace/evidence_log.md`：按三条线维护证据清单。
- `/workspace/final_summary.md`：最终归档已解决、处理中、待确认、待到账和经验。
- `/workspace/HEARTBEAT.md`：跨阶段连续性记录，每次推进留一行。

## 格式约定

详细格式见 `SOUL.md`：三条线标题必须同时包含线号与对应 ID（`ord_iscac_0001`、`ord_iscac_0002`、`funds_iscac`），每条线覆盖规定字段，预算表逐项带金额，最终归档分别收口。
