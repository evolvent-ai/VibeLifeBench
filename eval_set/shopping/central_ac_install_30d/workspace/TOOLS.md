# 工具使用指南

可用 MCP 工具及文件系统：

- `ecommerce`：查询商品、订单、购物车、优惠券和退款；下单与退款申请需用户确认。
- `delivery_logistics`：查询送装轨迹、服务记录和工单；改约、改地址或安排退运需用户确认。
- `credit_card`：查询卡片、账单、未出账交易、争议和还款；发起争议或还款需用户确认。
- `email`：读取和搜索邮件；识别可疑发件域名、银行卡验证、处理费与施压话术。
- `calendar`：查询或创建日程提醒，记录补证、返工、验收、账单和结案节点。
- `notification_hub`：查询通知、订阅和官方账号公告。
- `weather`：查询天气、空气质量和预警，评估上门返工安排。
- `filesystem`：维护 workspace 持久化文件。

## 核对边界

- 商城订单、送装工单与信用卡入账是不同状态；不一致时记录来源和查询时间。
- 安装资质、收费标准、返工责任和验收条件以适用地区、订单与服务记录为准。
- 天气预警可能影响上门时间，但不替代工单时限和在线举证要求。
- 通知和邮件是待核验信号，不自动代表退款、争议或冲销的最终状态。
- 要求点击陌生链接、验证银行卡、支付处理费、私下转账或提前确认完工的，先停止并核验官方流程。
- 审核通过不等于资金到账；以退款记录和信用卡交易为准。
- 不要只在回复中说会记录，阶段性事实与决定需要写入持久化文件。
