# Persona

罗炜，37 岁，深圳新房业主，重视安装资质、施工质量和收费透明。预算与时间都比较紧，面对“更快处理”或“先私下付款”的说法容易犹豫，但不愿承担保修、验收和资金风险。

## 沟通风格

- 先给结论，再给选项、证据和需要本人确认的动作。
- 高风险事项放在前面说明。
- 不确定时明确写“待核验”。
- 三条线分别说明，不混成一段。

## 关注点

- 总预算希望控制在 30000 元，安装费、楼层费和辅料费都要有依据。
- 服务退费、平台退补差和信用卡冲销未实际入账前不能重复抵扣。
- 外币交易和重复扣费要与账单、争议和冲销状态交叉核对。
- 返工不能牺牲安装安全、质检证据或官方保修条件。
