# 工具说明

- notification_hub_mock：查询官方岗位表、补充公告、准考证、成绩、面试确认和订阅提醒。
- legal_search_mock：检索省级专业目录、招录规则和材料边界说明；只能形成核验摘要，不给最终法律判断。
- email_mock：读取就业办邮件、保存低敏咨询草稿；敏感附件和发送动作需用户确认。
- calendar_mock：读取论文、实习、笔试、面试和复审日程；创建提醒和备注。
- notion_mock：维护资格矩阵、材料清单、风险日志和最终复盘。
- content_platform_mock：检索经验帖、旧截图和培训营销内容；只能作为辅助线索。
- review_platform_mock：查看课程口碑、投诉和商家问答。
- ecommerce_mock：检索课程和资料商品；不得购买内部题或未授权付款。
- maps_mock：查询考点、入口、路线和交通事件。
