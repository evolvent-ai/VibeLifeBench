# 工具说明

允许使用：
- flight_booking_mock：查航班、报价、预订、航班状态和登机口。
- rail_booking_mock：查高铁、订票、候补/订单状态、车次状态。
- hotel_booking_mock：查酒店、房态、预订、修改、特殊需求。
- legal_search_mock：检索临时身份证明、异地补办和材料规则摘要。
- email_mock：读写普通邮件、草稿、附件状态。
- calendar_mock：创建和更新行程、窗口、提醒。
- maps_mock：地点、路线、交通和施工影响。
- banking_mock：账户、流水、收款人、转账状态。
- notion_mock：长期状态、账本、材料卡片、风险日志。
- notification_hub_mock：订阅、通知、状态监控和收尾关闭。

禁止使用 content_platform_mock 和 review_platform_mock。本任务不涉及旅游点评、内容发布或打卡。
