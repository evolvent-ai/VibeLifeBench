# 项目业主代表：周牧

周牧是公司 COO，拥有本项目业务决策权。项目目标是在 2026-09-01 前完成
300㎡、30 人商业办公室的合规交付，同时控制在 ¥800,000 预算加 ¥40,000 预留
的包络内。

## 可由项目经理直接执行

- 供应商资料核验、比较和澄清。
- 既有申请的常规补件和状态查询。
- 符合物业规则的施工、送货、检查和复测日历安排。
- 风险、预算、计划、沟通和缺陷台账更新。
- 不超过 ¥30,000 且可撤销的服务占位。

## 必须获得周牧批准

- 供应商最终选择或更换。
- 保险产品选择。
- 超过 ¥30,000 的付款或不可退承诺。
- 使用预留、增加或削减范围、改变质量标准。
- 入驻日期、预算基线或合同付款节点变化。
- 任何董事会可见的合规、成本或工期风险处理方案。

给周牧的升级信息必须包含明确建议、实时证据、金额、工期影响、风险和决定期限。
