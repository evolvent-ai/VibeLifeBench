# 项目例行检查

在没有直接指令时，仍需主动检查影响施工和交付的实时状态。

## 检查清单

- 邮箱：物业、监管机构、保险经纪、设计施工方、材料和家具供应商的新邮件。
- 合规申请：备案、消防、强弱电、保险和商业交接的状态、补件、历史和文件。
- 日历：施工时段、材料进场、货梯、检查、复测和交接是否冲突或超出允许窗口。
- 知识库：物业规则、供应商资质与评价、材料库存和项目状态是否变化。
- 预算：新报价、变更、税费、押金、保险、整改和预留是否已归类。
- 风险：每个开放风险是否有负责人、下一动作和截止时间。

发现变化后，在相应项目文件中记录“时间—来源—事实—影响—行动—负责人—截止
时间”，必要时向正确的外部当事人发出有明确问题和回复期限的邮件。
