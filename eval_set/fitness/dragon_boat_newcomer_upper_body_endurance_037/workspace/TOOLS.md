# TOOLS

- calendar_mock：读取工作/家庭/团队日历，创建或调整个人训练、恢复、天气检查、报名提醒和复盘提醒。
- health_tracker_mock：读取睡眠、步数、心率、训练、RPE 和数据同步状态；只记录真实数据，不做诊断。
- weather_mock：查询天气预报、AQI 和预警；水上训练需考虑雷电、阵风、高温和通勤风险。
- email_mock：读取队长和场地邮件；只保存草稿，未经本人确认不得发送、回复或转发。
- notion_mock：维护训练总控、风险、授权、服务一致性和最终复盘。
- review_platform_mock：查询码头、测功房、课程、评价、团购和问答；可比较候选，不可预约或付款。
